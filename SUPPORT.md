# Support

For non-sensitive questions, use the [HADES community](https://discord.gg/BpEGzWwGYf). For reproducible bugs or improvements, use the [repository's issue templates](https://github.com/scottgigawatt/scripts/issues/new/choose). You can report a problem without first joining Discord.

## Include useful evidence

Share the exact script path and commit, your operating system and version, the relevant interpreter or external command versions, a sanitized command, and expected versus actual behavior. Include a minimal filename or directory example when it helps explain the problem.

For repository checks, include the target you ran and its relevant output. For filesystem tools, identify whether you used a disposable copy, preview mode, or execution mode. For Automator, identify the workflow, application, macOS version, and permission state.

Remove credentials, webhook URLs, personal paths, and private logs before posting. Report security concerns using the [private reporting policy](SECURITY.md).

## Set expectations

These independent tools have different dependencies and platform assumptions. Check the selected file's usage, the [README inventory](README.md#choose-a-tool), and [testing guidance](docs/testing.md) before opening an issue. Support is provided as maintainer time permits.
